# Hadith study-desk reference

[reference.html](reference.html) is an unchanged copy of Moath's `tawaq-study-desk.html` attachment, received on 2026-10-07. Moath selected its study-desk structure and authorized adapting unsupported features and compact layouts.

Moath subsequently requested cards and grade presentation that fit Tawaq better. The spec replaces the HTML's colored grade pills, tinted panels and inset stripes with quiet themed cards and neutral, labeled source rulings. The HTML remains an archive of the original structure; its card/grade styling is superseded.

The HTML is a visual and interaction reference, not a source of religious content or SDK capability claims. Its records, counts, category labels, cache state, error timings and availability indicators are illustrative. Several controls are inert; it has no responsive layout rules beyond reduced motion. It loads fonts from Google Fonts. None of those behaviors should be copied into production by assumption.

The implementation contract is [the study-desk spec](../../specs/hadith-study-desk-2026-10-07.md). It identifies the supported SDK behavior, deliberate adaptations and cleanup requirements. The application shell remains owned by Tawaq.
